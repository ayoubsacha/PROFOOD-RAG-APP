# Manuel détaillé — Comment choisir un fournisseur d’équipements professionnels

## Objectif du manuel

Ce manuel aide les professionnels de la restauration, boulangerie, pâtisserie, café, snack, hôtel, traiteur, fournisseur et distributeur à choisir correctement un fournisseur d’équipements professionnels.

Il sert de source documentaire pour le spécialiste IA “Fournisseurs” ou “Équipements Professionnels” de la plateforme ProFood.

Le manuel couvre :
- l’analyse du besoin avant de chercher un fournisseur ;
- les critères de sélection d’un fournisseur d’équipements ;
- les types de fournisseurs ;
- les garanties, SAV, livraison et installation ;
- les questions à poser avant achat ;
- la comparaison entre fournisseurs ;
- les risques à éviter ;
- les critères spécifiques par activité ;
- une grille de score pour choisir le meilleur fournisseur.

---

## 1. Comprendre le besoin avant de choisir un fournisseur

Avant de choisir un fournisseur d’équipements professionnels, il faut définir le besoin exact.

Un bon fournisseur n’est pas seulement celui qui propose le prix le plus bas. C’est celui qui peut fournir un équipement adapté, fiable, installé correctement, avec un service après-vente disponible.

Le client professionnel doit clarifier :
- son type d’activité ;
- les équipements nécessaires ;
- le volume de production ;
- le budget disponible ;
- l’espace disponible ;
- l’énergie disponible : gaz, électricité, triphasé ;
- le niveau de qualité recherché ;
- le besoin de livraison ;
- le besoin d’installation ;
- le besoin de formation ;
- le besoin de maintenance ;
- le délai souhaité ;
- la ville ou zone de livraison.

Exemple :
Une boulangerie qui achète un four ne doit pas choisir seulement selon le prix. Elle doit vérifier la capacité, la consommation, l’installation, la garantie, le SAV et la disponibilité des pièces.

## 2. Types de fournisseurs d’équipements

## 2.1 Fabricant

Un fabricant produit directement les équipements.

Avantages :
- meilleure connaissance technique ;
- pièces d’origine ;
- garantie claire ;
- personnalisation possible ;
- support direct.

Inconvénients :
- prix parfois plus élevé ;
- délais plus longs ;
- choix limité à sa marque ;
- présence locale parfois limitée.

## 2.2 Distributeur officiel

Un distributeur officiel revend une ou plusieurs marques avec autorisation.

Avantages :
- garantie reconnue ;
- accès aux pièces ;
- SAV plus fiable ;
- formation possible ;
- documentation technique.

Inconvénients :
- prix plus élevé qu’un revendeur non officiel ;
- dépendance à certaines marques.

## 2.3 Revendeur multi-marques

Un revendeur propose plusieurs marques et gammes.

Avantages :
- choix large ;
- comparaison facile ;
- possibilité de trouver plusieurs budgets ;
- disponibilité parfois rapide.

Inconvénients :
- qualité variable ;
- SAV dépend du revendeur ;
- certaines marques peuvent ne pas avoir de pièces disponibles.

## 2.4 Fournisseur local

Un fournisseur local intervient dans une ville ou région.

Avantages :
- proximité ;
- livraison rapide ;
- intervention plus simple ;
- relation directe ;
- connaissance du marché local.

Inconvénients :
- catalogue limité ;
- prix parfois moins compétitif ;
- disponibilité variable.

## 2.5 Fournisseur d’occasion

Il vend des équipements déjà utilisés.

Avantages :
- prix réduit ;
- disponibilité immédiate ;
- utile pour démarrage avec budget limité.

Risques :
- usure cachée ;
- absence garantie ;
- pièces indisponibles ;
- consommation plus élevée ;
- panne rapide ;
- hygiène ou état incertain.

## 2.6 Fournisseur spécialisé

Il se spécialise dans un domaine.

Exemples :
- fournisseur boulangerie ;
- fournisseur café ;
- fournisseur froid professionnel ;
- fournisseur cuisine CHR ;
- fournisseur pizzeria ;
- fournisseur laverie professionnelle.

Avantage :
Il comprend mieux les contraintes du métier.

## 3. Critères principaux pour choisir un fournisseur d’équipements

## 3.1 Spécialisation métier

Le fournisseur doit comprendre le métier du client.

Exemples :
- Pour une boulangerie : four, pétrin, fermentation, laminoir.
- Pour un restaurant : cuisson, froid, lavage, préparation.
- Pour un café : machine à café, moulin, lave-verres, vitrine.
- Pour un snack : friteuse, plancha, hotte, congélateur.
- Pour un traiteur : mobilité, maintien chaud/froid, transport.

Un fournisseur spécialisé donne de meilleurs conseils.

## 3.2 Qualité des marques proposées

À vérifier :
- marques connues ;
- réputation ;
- disponibilité des pièces ;
- durée de vie ;
- consommation énergétique ;
- facilité de maintenance ;
- documentation ;
- avis professionnels.

Un fournisseur qui vend des marques inconnues sans pièces disponibles peut devenir risqué.

## 3.3 Conseil avant achat

Un bon fournisseur doit poser des questions :
- type d’activité ;
- nombre de clients ;
- volume de production ;
- espace disponible ;
- budget ;
- énergie disponible ;
- usage quotidien ;
- besoin de maintenance.

S’il propose directement un produit sans comprendre le besoin, c’est un signe d’alerte.

## 3.4 Disponibilité des équipements

À vérifier :
- stock disponible ;
- délai de livraison ;
- délai d’importation ;
- alternatives en cas de rupture ;
- disponibilité des accessoires ;
- disponibilité pièces.

Pour un équipement critique, le délai est très important.

## 3.5 Prix clair

Le prix doit être complet.

À vérifier :
- prix équipement ;
- livraison ;
- installation ;
- accessoires ;
- formation ;
- garantie ;
- mise en service ;
- taxes ;
- frais déplacement ;
- contrat maintenance ;
- pièces supplémentaires.

Un prix bas peut cacher des frais non inclus.

## 3.6 Garantie

La garantie doit être écrite.

À vérifier :
- durée ;
- pièces couvertes ;
- main-d’œuvre couverte ou non ;
- déplacement inclus ou non ;
- conditions d’annulation ;
- exclusions ;
- délai d’intervention ;
- garantie fournisseur ou constructeur.

## 3.7 Service après-vente

Le SAV est l’un des critères les plus importants.

À vérifier :
- techniciens disponibles ;
- intervention dans votre ville ;
- délai moyen ;
- pièces disponibles ;
- réparation sur site ;
- assistance téléphonique ;
- contrat de maintenance ;
- réparation garantie ;
- rapport d’intervention.

Un équipement professionnel sans SAV fiable est un risque majeur.

## 3.8 Installation

Certains équipements nécessitent une installation professionnelle.

Exemples :
- four gaz ;
- chambre froide ;
- hotte ;
- lave-vaisselle ;
- machine à café ;
- équipement triphasé ;
- équipement frigorifique.

À vérifier :
- installation incluse ;
- technicien qualifié ;
- test de fonctionnement ;
- formation utilisateur ;
- conformité ;
- garantie installation.

## 3.9 Formation utilisateur

Un fournisseur sérieux peut former le personnel.

Formation utile pour :
- four mixte ;
- machine à café ;
- lave-vaisselle ;
- chambre froide ;
- pétrin ;
- cellule de refroidissement ;
- équipement de sécurité.

## 3.10 Documentation

Le fournisseur doit fournir :
- facture ;
- garantie ;
- fiche technique ;
- manuel utilisateur ;
- manuel maintenance ;
- certificat conformité si disponible ;
- conditions SAV ;
- conseils nettoyage.

## 3.11 Réputation

À vérifier :
- avis clients ;
- références ;
- ancienneté ;
- photos installations ;
- clients similaires ;
- présence locale ;
- comportement après-vente.

## 3.12 Proximité géographique

La proximité est importante pour :
- livraison ;
- installation ;
- intervention rapide ;
- pièces ;
- suivi.

Pour un équipement critique, un fournisseur proche est souvent préférable à un fournisseur très loin mais moins cher.

## 4. Questions à poser au fournisseur

Avant d’acheter, poser ces questions :

1. Est-ce que cet équipement est adapté à mon activité ?
2. Quelle capacité recommandez-vous pour mon volume ?
3. Le prix inclut-il livraison et installation ?
4. Quelle est la durée de garantie ?
5. Le SAV intervient-il dans ma ville ?
6. Quel est le délai moyen d’intervention ?
7. Les pièces de rechange sont-elles disponibles ?
8. L’équipement est-il neuf ou d’occasion ?
9. Puis-je voir une fiche technique ?
10. Quelle est la consommation énergétique ?
11. L’équipement nécessite-t-il triphasé, gaz ou arrivée d’eau ?
12. Faites-vous la mise en service ?
13. Formez-vous le personnel ?
14. Que se passe-t-il en cas de panne ?
15. Existe-t-il un contrat de maintenance ?
16. Le produit est-il disponible immédiatement ?
17. Quels accessoires sont inclus ?
18. Puis-je comparer avec un autre modèle ?
19. Avez-vous des références clients ?
20. Quelle est la politique de retour ?

## 5. Choisir selon le type d’activité

## 5.1 Restaurant

Fournisseur à privilégier :
- fournisseur CHR ;
- fournisseur cuisine professionnelle ;
- fournisseur froid ;
- fournisseur lavage ;
- fournisseur ventilation.

Critères prioritaires :
- large catalogue ;
- installation ;
- SAV rapide ;
- conseils sur capacité ;
- équipement robuste ;
- conformité hygiène ;
- disponibilité pièces.

Équipements fréquents :
- four mixte ;
- piano cuisson ;
- friteuse ;
- plancha ;
- hotte ;
- armoire froide ;
- table réfrigérée ;
- lave-vaisselle ;
- tables inox.

## 5.2 Boulangerie

Fournisseur à privilégier :
- fournisseur spécialisé boulangerie/pâtisserie.

Critères prioritaires :
- connaissance fermentation et cuisson ;
- four adapté ;
- pétrin adapté ;
- maintenance rapide ;
- pièces disponibles ;
- installation correcte ;
- formation.

Équipements fréquents :
- four à sole ;
- four rotatif ;
- pétrin ;
- chambre fermentation ;
- diviseuse ;
- façonneuse ;
- laminoir ;
- chariots ;
- plaques.

## 5.3 Pâtisserie

Fournisseur à privilégier :
- fournisseur pâtisserie ;
- fournisseur froid ;
- fournisseur vitrines.

Critères prioritaires :
- précision température ;
- matériel propre et esthétique ;
- vitrines fiables ;
- cellule refroidissement ;
- SAV froid ;
- régularité.

## 5.4 Café

Fournisseur à privilégier :
- fournisseur machine café ;
- fournisseur bar ;
- fournisseur boissons.

Critères prioritaires :
- machine fiable ;
- maintenance rapide ;
- pièces café disponibles ;
- formation barista ;
- moulin adapté ;
- contrat entretien.

## 5.5 Snack / fast-food

Fournisseur à privilégier :
- fournisseur cuisson rapide ;
- fournisseur froid compact ;
- fournisseur hotte.

Critères prioritaires :
- prix ;
- robustesse ;
- rapidité livraison ;
- SAV ;
- équipement compact ;
- sécurité incendie.

## 5.6 Traiteur

Fournisseur à privilégier :
- fournisseur matériel mobile ;
- fournisseur maintien chaud/froid ;
- fournisseur transport alimentaire.

Critères prioritaires :
- mobilité ;
- résistance ;
- maintien température ;
- chariots ;
- conteneurs isothermes ;
- disponibilité événementielle.

## 5.7 Hôtel

Fournisseur à privilégier :
- fournisseur CHR grande capacité ;
- fournisseur multi-équipements ;
- fournisseur SAV structuré.

Critères prioritaires :
- volume ;
- garantie ;
- contrat maintenance ;
- installation complète ;
- formation ;
- disponibilité continue.

## 6. Fournisseur neuf ou occasion

## 6.1 Fournisseur neuf

À privilégier pour :
- équipements critiques ;
- équipements de froid ;
- cuisson intensive ;
- machine café principale ;
- équipements gaz ;
- équipements avec sécurité.

Avantages :
- garantie ;
- moins de panne ;
- durée de vie ;
- installation ;
- conformité ;
- documentation.

## 6.2 Fournisseur occasion

Possible pour :
- tables inox ;
- rayonnages ;
- chariots ;
- certains petits équipements ;
- équipements secondaires testés.

À éviter en occasion si :
- pas de garantie ;
- pas de test ;
- pas de facture ;
- équipement critique ;
- froid instable ;
- gaz douteux ;
- machine très ancienne ;
- pièces indisponibles.

Questions spécifiques occasion :
1. Quel âge a l’équipement ?
2. Pourquoi est-il vendu ?
3. Peut-on le tester ?
4. Y a-t-il une garantie ?
5. Y a-t-il facture ?
6. Les pièces sont-elles disponibles ?
7. Y a-t-il un historique maintenance ?
8. L’état hygiène est-il correct ?

---

## 7. Comparer plusieurs fournisseurs

Comparer au moins 2 ou 3 fournisseurs.

Critères de comparaison :
- prix total ;
- marque ;
- capacité ;
- garantie ;
- SAV ;
- installation ;
- livraison ;
- pièces ;
- délai ;
- réputation ;
- conseil ;
- formation ;
- maintenance ;
- proximité.

Ne pas comparer seulement le prix affiché.

Comparer le coût total :
prix achat + livraison + installation + maintenance + énergie + pièces + risque panne.

---

## 8. Signes d’un bon fournisseur

Un bon fournisseur :
- écoute le besoin ;
- pose des questions ;
- recommande plusieurs options ;
- explique les avantages et limites ;
- fournit devis clair ;
- donne fiche technique ;
- propose garantie ;
- propose SAV ;
- peut installer ;
- fournit facture ;
- connaît le secteur ;
- ne pousse pas toujours le plus cher ;
- peut former l’utilisateur.

---

## 9. Signes d’alerte

Éviter un fournisseur qui :
- refuse un devis écrit ;
- ne donne pas de garantie ;
- ne donne pas de fiche technique ;
- ne connaît pas l’usage professionnel ;
- propose un prix trop bas sans explication ;
- n’a pas de SAV ;
- n’a pas de pièces ;
- ne peut pas installer ;
- donne des délais flous ;
- refuse le test en occasion ;
- n’a pas de références ;
- ne donne pas de facture.

## 11. Checklist avant validation

Avant de valider le fournisseur, vérifier :

- Le besoin est bien défini.
- Le fournisseur comprend mon activité.
- Le devis est complet.
- La garantie est écrite.
- Le SAV est disponible.
- Les pièces sont disponibles.
- La livraison est claire.
- L’installation est incluse ou chiffrée.
- La formation est prévue si nécessaire.
- Le prix total est connu.
- L’équipement est adapté à mon local.
- Les dimensions sont vérifiées.
- L’énergie nécessaire est disponible.
- La fiche technique est fournie.
- La facture sera fournie.
- J’ai comparé plusieurs offres.

## 12. Comment le spécialiste IA doit utiliser ce manuel

Le spécialiste IA doit :
- identifier l’activité du client ;
- identifier le type d’équipement recherché ;
- demander la ville, budget, urgence ou volume si nécessaire ;
- recommander les critères de choix du fournisseur ;
- expliquer pourquoi le SAV et les pièces sont essentiels ;
- comparer fournisseur local, distributeur officiel, occasion ou neuf ;
- proposer une checklist ;
- éviter d’inventer un fournisseur réel non présent dans la base ;
- utiliser les données ProFood si disponibles.

Exemple de réponse attendue :
Pour choisir un fournisseur de four professionnel pour une boulangerie, il faut privilégier un fournisseur spécialisé boulangerie, capable d’assurer l’installation, le réglage, la formation, le SAV rapide et la disponibilité des pièces. Le prix ne doit pas être le seul critère, car une panne de four peut bloquer toute la production.
