# Manuel détaillé — Comment choisir un service professionnel pour son activité

## Objectif du manuel

Ce manuel aide les professionnels de la restauration, boulangerie, pâtisserie, café, snack, hôtel, traiteur, distributeur alimentaire et fournisseur B2B à choisir correctement leurs prestataires de services.

Il sert de source documentaire pour le spécialiste IA “Services Professionnels” de la plateforme ProFood.

Le manuel couvre :
- l’analyse du besoin avant de choisir un service ;
- les critères généraux de sélection d’un prestataire ;
- les services de livraison et logistique ;
- les services de maintenance ;
- les services de nettoyage et hygiène ;
- les services d’installation ;
- les services de réparation et SAV ;
- les services de conseil et accompagnement ;
- les services de formation ;
- les services informatiques et digitaux ;
- les services de sécurité ;
- les contrats, SLA, garanties et indicateurs de performance ;
- les erreurs à éviter ;
- une grille de score pour comparer plusieurs prestataires.

---

## 1. Comprendre le besoin avant de choisir un service

Avant de choisir un service, le client professionnel doit comprendre exactement ce dont il a besoin.

Un bon service n’est pas forcément le moins cher. C’est celui qui correspond :
- au type d’activité ;
- au niveau d’urgence ;
- à la fréquence du besoin ;
- au budget ;
- à la localisation ;
- aux contraintes d’hygiène ;
- aux contraintes de sécurité ;
- au volume de travail ;
- au niveau de qualité attendu ;
- à la disponibilité du prestataire ;
- à la clarté du contrat ;
- au niveau de suivi et de garantie.

Exemples :
- Un restaurant a besoin d’un service de maintenance rapide pour éviter l’arrêt de la cuisine.
- Une boulangerie a besoin d’un technicien capable d’intervenir sur les fours, pétrins et chambres de fermentation.
- Un café a besoin d’un service fiable pour la machine à café et le lave-verres.
- Un traiteur a besoin d’un service de livraison ponctuel, capable de maintenir les produits à bonne température.
- Un hôtel a besoin de nettoyage régulier, hygiène stricte, maintenance préventive et disponibilité continue.

## 2. Questions à poser avant de choisir un prestataire

Avant de signer avec un prestataire, il faut répondre à ces questions :

1. Quel problème dois-je résoudre ?
2. Le service est-il ponctuel ou régulier ?
3. Le service est-il critique pour mon activité ?
4. Quel est le délai d’intervention attendu ?
5. Le prestataire travaille-t-il dans mon secteur ?
6. Le prestataire comprend-il les contraintes alimentaires ?
7. Le prestataire intervient-il dans ma ville ?
8. Dispose-t-il d’expérience avec restaurants, boulangeries, cafés ou hôtels ?
9. Le prix est-il clair ?
10. Le devis inclut-il déplacement, main-d’œuvre, pièces, produits ou matériel ?
11. Existe-t-il une garantie ?
12. Existe-t-il un contrat ou SLA ?
13. Comment la qualité est-elle mesurée ?
14. Comment signaler un problème ?
15. Que se passe-t-il si le service n’est pas conforme ?

## 3. Critères généraux pour choisir un service professionnel

Chaque service doit être évalué selon plusieurs critères.

### 3.1 Compétence du prestataire

À vérifier :
- expérience ;
- spécialisation ;
- références clients ;
- certifications si nécessaires ;
- connaissance du secteur alimentaire ;
- capacité à traiter le besoin exact ;
- qualification de l’équipe ;
- qualité du diagnostic ;
- clarté des explications.

Un prestataire compétent doit comprendre l’impact du service sur l’activité professionnelle.

### 3.2 Fiabilité

Un service fiable respecte :
- les délais ;
- les horaires ;
- les engagements ;
- la qualité attendue ;
- les règles d’hygiène ;
- les règles de sécurité ;
- la confidentialité si nécessaire.

La fiabilité est particulièrement importante pour les services de livraison, maintenance et nettoyage.

### 3.3 Disponibilité

À vérifier :
- jours d’intervention ;
- horaires ;
- disponibilité en urgence ;
- délai moyen de réponse ;
- délai moyen d’intervention ;
- couverture géographique ;
- capacité à intervenir pendant les périodes de forte activité.

Exemple :
Pour une boulangerie, une panne de four tôt le matin peut bloquer toute la production. Le prestataire doit donc offrir une intervention rapide.

### 3.4 Prix

Le prix doit être clair et complet.

À vérifier :
- prix fixe ou horaire ;
- frais de déplacement ;
- main-d’œuvre ;
- pièces ;
- produits ;
- matériel ;
- urgence ;
- abonnement ;
- taxes ;
- conditions de paiement.

Un service moins cher peut devenir coûteux s’il provoque des retards, des pannes répétées ou une mauvaise qualité.

### 3.5 Qualité du service

La qualité se mesure par :
- résultat obtenu ;
- respect des délais ;
- propreté du travail ;
- durabilité ;
- communication ;
- rapport d’intervention ;
- suivi ;
- satisfaction client.

### 3.6 Garantie

À vérifier :
- durée de garantie ;
- ce qui est couvert ;
- ce qui n’est pas couvert ;
- délai de correction ;
- conditions d’annulation ;
- responsabilité du prestataire.

### 3.7 Contrat et SLA

Un SLA, ou accord de niveau de service, sert à définir clairement les services attendus, les indicateurs de performance, les responsabilités et les conséquences si le niveau de service n’est pas respecté.

Dans un contexte ProFood, un SLA peut préciser :
- délai de réponse ;
- délai d’intervention ;
- taux de disponibilité ;
- délai de livraison ;
- qualité attendue ;
- fréquence de nettoyage ;
- fréquence de maintenance ;
- pénalités ou actions correctives ;
- responsabilités de chaque partie.

### 3.8 Communication

Un bon prestataire doit :
- répondre clairement ;
- expliquer le problème ;
- donner un devis compréhensible ;
- informer en cas de retard ;
- fournir un rapport ;
- proposer des recommandations ;
- garder un historique des interventions.

### 3.9 Sécurité et conformité

Pour les activités alimentaires, un service doit respecter :
- hygiène ;
- sécurité du personnel ;
- sécurité alimentaire ;
- normes d’installation ;
- manipulation correcte des produits ;
- respect des locaux ;
- séparation des zones propres/sales ;
- protection des denrées alimentaires.

## 4. Grandes familles de services professionnels

## 4.1 Service de livraison et logistique

Le service de livraison est essentiel pour les fournisseurs, restaurants, traiteurs, cafés, hôtels et distributeurs.

### Types de livraison

- livraison alimentaire sèche ;
- livraison produits frais ;
- livraison produits surgelés ;
- livraison équipements ;
- livraison express ;
- livraison planifiée ;
- livraison multi-adresses ;
- livraison événementielle ;
- livraison B2B entre fournisseur et client pro ;
- livraison dernier kilomètre.

### Critères de choix

À vérifier :
- ponctualité ;
- zone couverte ;
- délais ;
- capacité de transport ;
- respect chaîne du froid ;
- traçabilité ;
- suivi de commande ;
- assurance ;
- état du véhicule ;
- hygiène du transport ;
- qualité de communication ;
- politique en cas de retard ;
- coût par livraison ;
- possibilité de livraison urgente.

### Pour les produits alimentaires

Le prestataire doit garantir :
- véhicule propre ;
- température adaptée ;
- séparation des produits ;
- emballages protégés ;
- respect des horaires ;
- preuve de livraison ;
- gestion des retours ;
- traçabilité.

### Pour les équipements

Le prestataire doit garantir :
- manutention correcte ;
- protection contre les chocs ;
- véhicule adapté ;
- personnel formé ;
- livraison à l’intérieur du local si nécessaire ;
- installation ou positionnement si inclus ;
- assurance casse.

### Indicateurs de performance

- taux de livraison à l’heure ;
- taux de livraison complète ;
- taux de produits endommagés ;
- délai moyen ;
- taux de réclamation ;
- respect température ;
- coût moyen par livraison.

### Questions à poser

1. Livrez-vous dans ma ville ?
2. Travaillez-vous avec produits alimentaires ?
3. Respectez-vous la chaîne du froid ?
4. Avez-vous des véhicules frigorifiques ?
5. Comment suivez-vous les livraisons ?
6. Que se passe-t-il en cas de retard ?
7. Que se passe-t-il si un produit est endommagé ?
8. Fournissez-vous une preuve de livraison ?
9. Livrez-vous le week-end ?
10. Proposez-vous un service express ?

### Erreurs à éviter

- choisir seulement le prix ;
- ignorer la chaîne du froid ;
- ne pas vérifier l’assurance ;
- ne pas définir les horaires ;
- ne pas prévoir la gestion des retours ;
- accepter des livraisons sans preuve ;
- utiliser un prestataire non adapté aux produits alimentaires.

## 4.2 Service de maintenance

La maintenance permet d’éviter les pannes et d’allonger la durée de vie des équipements.

### Types de maintenance

- maintenance préventive ;
- maintenance corrective ;
- maintenance urgente ;
- maintenance annuelle ;
- maintenance sous contrat ;
- maintenance frigorifique ;
- maintenance cuisson ;
- maintenance machines café ;
- maintenance lave-vaisselle ;
- maintenance ventilation/hotte ;
- maintenance électrique ;
- maintenance plomberie.

### Maintenance préventive

Objectif :
éviter les pannes avant qu’elles arrivent.

Exemples :
- nettoyage condenseur chambre froide ;
- contrôle thermostat ;
- vérification joints ;
- détartrage machine café ;
- contrôle brûleurs ;
- contrôle sécurité gaz ;
- inspection moteur pétrin ;
- nettoyage filtres hotte.

Avantages :
- moins de pannes ;
- durée de vie plus longue ;
- meilleure sécurité ;
- économie long terme ;
- meilleure continuité d’activité.

### Maintenance corrective

Objectif :
réparer après une panne.

Exemples :
- four qui ne chauffe plus ;
- friteuse en panne ;
- chambre froide trop chaude ;
- lave-vaisselle qui fuit ;
- machine à café bloquée.

### Critères de choix

À vérifier :
- compétence technique ;
- spécialisation par équipement ;
- délai d’intervention ;
- disponibilité urgence ;
- pièces de rechange ;
- garantie réparation ;
- rapport d’intervention ;
- contrat possible ;
- prix clair ;
- proximité géographique.

### Équipements critiques

Pour les équipements critiques, choisir un prestataire très fiable.

Exemples :
- four principal ;
- chambre froide ;
- machine à café principale ;
- friteuse principale ;
- lave-vaisselle d’un grand restaurant ;
- pétrin d’une boulangerie.

Pour ces équipements, il faut :
- intervention rapide ;
- pièces disponibles ;
- contrat maintenance ;
- technicien spécialisé ;
- solution temporaire si possible.

### Questions à poser

1. Quels équipements réparez-vous ?
2. Intervenez-vous en urgence ?
3. Quel est votre délai moyen ?
4. Avez-vous les pièces en stock ?
5. La réparation est-elle garantie ?
6. Fournissez-vous un rapport ?
7. Proposez-vous un contrat annuel ?
8. Travaillez-vous avec les marques que j’utilise ?
9. Intervenez-vous dans ma ville ?
10. Pouvez-vous faire une maintenance préventive ?

### Indicateurs de performance

- délai de réponse ;
- délai d’intervention ;
- taux de panne répétée ;
- taux de réparation réussie ;
- disponibilité pièces ;
- coût moyen intervention ;
- satisfaction client ;
- temps d’arrêt évité.

## 4.5 Service de réparation et SAV

Le SAV intervient après l’achat ou l’installation.

### Types de SAV

- réparation sous garantie ;
- réparation hors garantie ;
- remplacement pièces ;
- diagnostic ;
- assistance téléphonique ;
- visite technique ;
- mise à jour matériel ;
- retour fournisseur ;
- remplacement équipement.

### Critères de choix

À vérifier :
- délai de réponse ;
- garantie intervention ;
- disponibilité pièces ;
- compétence marque ;
- prix diagnostic ;
- transparence ;
- historique intervention ;
- proximité ;
- qualité communication.

### Bon SAV

Un bon SAV doit :
- répondre rapidement ;
- diagnostiquer clairement ;
- donner un devis ;
- réparer proprement ;
- tester après réparation ;
- expliquer les causes ;
- proposer prévention ;
- garantir l’intervention.

### Mauvais SAV

Signes d’alerte :
- pas de réponse ;
- devis flou ;
- pièces inconnues ;
- retard répété ;
- panne qui revient ;
- pas de garantie ;
- communication faible ;
- absence de rapport.

## 6. Contrat, devis et SLA

## 6.1 Devis

Un bon devis doit contenir :
- description du service ;
- prix détaillé ;
- fréquence ;
- durée ;
- frais supplémentaires ;
- matériel inclus ;
- produits inclus ;
- conditions paiement ;
- garantie ;
- exclusions ;
- délai intervention ;
- validité du devis.

## 6.2 Contrat

Un contrat doit préciser :
- les parties ;
- le périmètre ;
- la durée ;
- les obligations ;
- les horaires ;
- le prix ;
- les modalités d’annulation ;
- les responsabilités ;
- la confidentialité ;
- l’assurance ;
- la résolution des litiges.

## 6.3 SLA

Un SLA doit définir :
- niveau de service attendu ;
- indicateurs ;
- délais ;
- responsabilités ;
- fréquence ;
- méthode de mesure ;
- actions correctives ;
- pénalités si prévues.

Exemples :
- Maintenance : intervention sous 24h pour équipement critique.
- Livraison : 95 % des livraisons à l’heure.
- Nettoyage : passage quotidien avec checklist signée.
- Informatique : support sous 4h ouvrées.
- SAV : diagnostic sous 48h.

## 8. Comparer plusieurs prestataires

Pour comparer, utiliser une matrice.

Critères :
- prix ;
- expérience ;
- disponibilité ;
- délai ;
- garantie ;
- qualité ;
- références ;
- proximité ;
- communication ;
- conformité ;
- SAV ;
- flexibilité.

Il faut comparer au moins 2 ou 3 prestataires avant un service important.

Ne pas comparer uniquement le prix. Comparer le coût total :
- prix direct ;
- temps perdu ;
- risque panne ;
- risque retard ;
- qualité ;
- conséquences d’un mauvais service.

## 9. Erreurs fréquentes à éviter

1. Choisir le service le moins cher sans vérifier la qualité.
2. Ne pas demander de devis détaillé.
3. Ne pas vérifier les références.
4. Ne pas définir les délais.
5. Ne pas prévoir de garantie.
6. Ne pas exiger de rapport d’intervention.
7. Ne pas vérifier l’assurance.
8. Choisir un prestataire non spécialisé dans l’alimentaire.
9. Ne pas clarifier ce qui est inclus.
10. Ne pas mesurer la performance.
11. Ne pas prévoir solution en urgence.
12. Signer un contrat flou.
13. Ne pas former le personnel après installation.
14. Ignorer le coût d’une panne.
15. Ne pas conserver historique des interventions.

## 10. Signes d’un bon prestataire

Un bon prestataire :
- comprend le besoin ;
- pose des questions précises ;
- donne un devis clair ;
- explique les limites ;
- respecte les délais ;
- fournit une garantie ;
- communique bien ;
- a de bonnes références ;
- fournit un rapport ;
- accepte de mesurer la performance ;
- propose des solutions adaptées ;
- respecte l’hygiène et la sécurité.

---

## 11. Signes d’alerte

À éviter si le prestataire :
- refuse de donner un devis écrit ;
- ne précise pas les délais ;
- ne parle pas de garantie ;
- n’a pas de références ;
- ne répond pas clairement ;
- propose un prix trop bas sans explication ;
- ne connaît pas les contraintes alimentaires ;
- n’est pas assuré ;
- ne fournit pas de facture ;
- ne donne pas de rapport ;
- change souvent les conditions.
