# Manuel — Comment choisir son stock d’équipements professionnels

## Objectif du manuel

Ce manuel aide les professionnels de la restauration, boulangerie, pâtisserie, café, hôtellerie, snack, traiteur et distribution alimentaire à choisir correctement leur stock d’équipements professionnels.

Il sert de source documentaire pour le spécialiste IA “Équipements Professionnels” de la plateforme ProFood.

Le manuel couvre :
- l’analyse du besoin avant l’achat ;
- les critères de choix d’un équipement ;
- les familles d’équipements professionnels ;
- les équipements par type d’activité ;
- le dimensionnement de capacité ;
- la qualité, la sécurité, l’hygiène et la conformité ;
- l’énergie, la maintenance et la durée de vie ;
- la comparaison entre neuf et occasion ;
- la réception, l’installation et le suivi ;
- une grille de score pour recommander un équipement.

---

## 1. Comprendre le besoin avant d’acheter

Avant d’acheter un équipement professionnel, il faut d’abord comprendre le besoin réel de l’entreprise.

Un bon équipement n’est pas forcément le plus grand, le plus cher ou le plus moderne. C’est celui qui correspond exactement :
- au type d’activité ;
- au volume de production ;
- au menu ou aux produits vendus ;
- à l’espace disponible ;
- au budget ;
- à la consommation énergétique ;
- au niveau de compétence du personnel ;
- à la maintenance disponible ;
- aux règles d’hygiène et de sécurité ;
- à la fréquence d’utilisation.

Exemples :
- Une petite boulangerie n’a pas besoin du même four qu’une boulangerie industrielle.
- Un snack peut utiliser une plaque de cuisson compacte, alors qu’un restaurant à fort débit aura besoin d’un piano de cuisson professionnel.
- Un café peut privilégier une machine à café fiable et un petit réfrigérateur vitrine.
- Un traiteur doit choisir des équipements mobiles, résistants au transport et faciles à nettoyer.

---

## 2. Questions à poser avant le choix

Avant de choisir un équipement, le professionnel doit répondre à ces questions :

1. Quelle est mon activité principale ?
2. Quels produits vais-je préparer ou vendre ?
3. Quel volume dois-je produire par jour ?
4. Combien de clients vais-je servir ?
5. Quelle est la fréquence d’utilisation de l’équipement ?
6. Combien d’espace ai-je dans mon local ?
7. Quelle énergie est disponible : électricité, gaz, triphasé ?
8. Mon personnel sait-il utiliser cet équipement ?
9. L’équipement est-il facile à nettoyer ?
10. Existe-t-il un service après-vente local ?
11. Les pièces de rechange sont-elles disponibles ?
12. Quelle est la durée de garantie ?
13. Quel est le coût total sur plusieurs années ?
14. L’équipement respecte-t-il les normes d’hygiène ?
15. Est-ce que l’équipement améliore réellement ma productivité ?

## 3. Critères principaux pour choisir un équipement

Chaque équipement doit être évalué selon ces critères :

### 3.1 Adaptation à l’activité

L’équipement doit correspondre au métier.

Exemples :
- Boulangerie : four à sole, four ventilé, pétrin, diviseuse, chambre de fermentation.
- Restaurant : four mixte, piano de cuisson, friteuse, plancha, lave-vaisselle.
- Café : machine à café, moulin à café, réfrigérateur vitrine, lave-verres.
- Snack : friteuse, grill panini, plaque, congélateur, hotte.
- Traiteur : bacs gastronormes, chafing dishes, conteneurs isothermes, tables inox.

### 3.2 Capacité

La capacité doit être suffisante pour la production prévue.

Un équipement sous-dimensionné provoque :
- ralentissement du service ;
- files d’attente ;
- usure rapide ;
- stress du personnel ;
- perte de clients.

Un équipement surdimensionné provoque :
- coût d’achat trop élevé ;
- consommation énergétique inutile ;
- perte d’espace ;
- maintenance plus chère.

### 3.3 Qualité de fabrication

À vérifier :
- matériaux résistants ;
- inox alimentaire ;
- solidité des portes, poignées et charnières ;
- stabilité ;
- finitions faciles à nettoyer ;
- marque reconnue ;
- disponibilité des pièces.

### 3.4 Hygiène et facilité de nettoyage

Un équipement professionnel doit être facile à nettoyer.

À privilégier :
- surfaces lisses ;
- inox ;
- pièces démontables ;
- angles arrondis ;
- absence de zones difficiles à nettoyer ;
- accès facile aux filtres ;
- drainage correct ;
- compatibilité avec produits de nettoyage.

### 3.5 Sécurité

À vérifier :
- protection contre la surchauffe ;
- arrêt d’urgence ;
- stabilité ;
- isolation thermique ;
- système anti-fuite de gaz ;
- sécurité électrique ;
- conformité aux normes ;
- notice claire ;
- formation du personnel.

### 3.6 Consommation énergétique

L’équipement doit être évalué selon :
- puissance électrique ou gaz ;
- durée d’utilisation quotidienne ;
- rendement ;
- isolation ;
- classe énergétique si disponible ;
- consommation d’eau ;
- coût mensuel estimé.

Un équipement moins cher à l’achat peut coûter plus cher à long terme s’il consomme trop d’énergie.

### 3.7 Maintenance

À vérifier :
- fréquence d’entretien ;
- facilité de nettoyage quotidien ;
- disponibilité technicien local ;
- disponibilité pièces de rechange ;
- coût des réparations ;
- garantie ;
- contrat de maintenance possible.

### 3.8 Garantie et service après-vente

Un bon équipement doit avoir :
- garantie claire ;
- fournisseur joignable ;
- SAV local ou régional ;
- pièces disponibles ;
- délai de réparation acceptable ;
- documentation technique.

### 3.9 Coût total de possession

Le prix d’achat n’est qu’une partie du coût.

Coût total = prix d’achat + installation + consommation énergie/eau + maintenance + pièces + réparation + temps d’arrêt + formation + durée de vie.

## 4. Grandes familles d’équipements professionnels

## 4.1 Équipements de cuisson

Les équipements de cuisson servent à cuire, griller, frire, rôtir, mijoter ou réchauffer les aliments.

### A. Four professionnel

Types :
- four à convection ;
- four mixte ;
- four à sole ;
- four ventilé ;
- four à pizza ;
- four rotatif ;
- four pâtissier ;
- four basse température.

Critères de choix :
- type de cuisson ;
- nombre de niveaux ;
- capacité en plaques ;
- température maximale ;
- homogénéité de cuisson ;
- humidification ;
- programmation ;
- consommation énergétique ;
- facilité de nettoyage ;
- besoin en extraction ;
- espace disponible.

Usage :
- Restaurant : four mixte ou four convection.
- Boulangerie : four à sole ou four rotatif.
- Pâtisserie : four ventilé précis.
- Pizzeria : four à pizza.
- Traiteur : four mixte grande capacité.

À éviter :
- four trop petit pour le volume ;
- four sans SAV ;
- four difficile à nettoyer ;
- four avec mauvaise isolation ;
- four non adapté au produit principal.

### B. Piano de cuisson / cuisinière professionnelle

Critères :
- nombre de feux ;
- puissance ;
- gaz ou électrique ;
- four intégré ou non ;
- robustesse ;
- stabilité ;
- facilité de nettoyage ;
- compatibilité avec casseroles professionnelles.

Usage :
- restaurant traditionnel ;
- cuisine à la carte ;
- hôtel ;
- collectivité.

### C. Plaque de cuisson / plancha

Critères :
- surface utile ;
- matériau de la plaque ;
- montée en température ;
- répartition chaleur ;
- évacuation des graisses ;
- facilité de nettoyage.

Usage :
- burgers ;
- viandes ;
- poissons ;
- sandwiches ;
- légumes grillés ;
- snacks.

### D. Grill professionnel

Types :
- grill pierre de lave ;
- grill électrique ;
- grill gaz ;
- salamandre ;
- grill panini.

Critères :
- puissance ;
- rapidité ;
- surface ;
- nettoyage ;
- gestion des fumées ;
- sécurité.

### E. Friteuse professionnelle

Types :
- friteuse simple bac ;
- double bac ;
- friteuse sur coffre ;
- friteuse électrique ;
- friteuse gaz.

Critères :
- capacité en litres ;
- temps de chauffe ;
- zone froide ;
- vidange facile ;
- sécurité thermostat ;
- filtration huile ;
- consommation ;
- nettoyage.

Usage :
- snack ;
- restaurant ;
- fast-food ;
- poissonnerie ;
- traiteur.

À éviter :
- friteuse domestique pour usage professionnel ;
- friteuse sans vidange ;
- friteuse trop petite ;
- absence de sécurité thermique.

### F. Marmite / sauteuse / braisière

Usage :
- sauces ;
- soupes ;
- plats mijotés ;
- riz ;
- grandes quantités.

Critères :
- capacité ;
- basculement ;
- contrôle température ;
- nettoyage ;
- sécurité ;
- énergie.

### G. Cuiseur vapeur

Usage :
- légumes ;
- poisson ;
- riz ;
- cuisson saine ;
- restauration collective.

Critères :

## 6. Dimensionner un équipement

Le dimensionnement consiste à choisir la bonne capacité.

### Formule simple

Capacité nécessaire = production maximale prévue + marge de sécurité.

Exemple :
Un restaurant sert 80 couverts/jour et utilise 1 portion de frites pour 40 % des clients.
80 × 40 % = 32 portions/jour.
Si le service est concentré en 2 heures, la friteuse doit pouvoir produire au moins 32 portions sur cette période, avec une marge.

### Marge recommandée

Ajouter 10 % à 30 % de marge selon :
- variation de clientèle ;
- croissance prévue ;
- saisonnalité ;
- délai de remplacement ;
- importance de l’équipement.

### Attention

Ne pas dimensionner seulement selon le besoin actuel si l’activité va grandir rapidement.
Ne pas acheter trop grand si l’espace, l’énergie et le budget ne suivent pas.

## 7. Neuf ou occasion ?

## 7.1 Équipement neuf

Avantages :
- garantie ;
- meilleure hygiène ;
- durée de vie plus longue ;
- conformité plus facile ;
- moins de risque de panne ;
- documentation disponible.

Inconvénients :
- prix élevé ;
- délai de livraison possible ;
- coût installation.

À choisir neuf pour :
- réfrigération ;
- cuisson intensive ;
- équipements de sécurité ;
- machines très utilisées ;
- équipement critique.

## 7.2 Équipement d’occasion

Avantages :
- prix plus bas ;
- disponibilité rapide ;
- intéressant pour démarrage.

Risques :
- panne ;
- absence garantie ;
- pièces indisponibles ;
- usure cachée ;
- consommation plus élevée ;
- hygiène incertaine.

À vérifier avant achat occasion :
- état général ;
- facture ;
- marque/modèle ;
- âge ;
- test fonctionnement ;
- pièces disponibles ;
- traces rouille ;
- joints ;
- moteur ;
- température réelle ;
- historique maintenance.

À éviter d’occasion :
- équipement très ancien ;
- réfrigérateur avec mauvais froid ;
- friteuse rouillée ;
- machine sans pièces ;
- four avec porte abîmée ;
- équipement sans test.

## 9. Réception et installation

À la réception :
- vérifier emballage ;
- vérifier modèle ;
- vérifier accessoires ;
- vérifier état ;
- vérifier facture ;
- tester fonctionnement ;

À l’installation :

## 10. Maintenance préventive

Un équipement bien entretenu dure plus longtemps.

Maintenance quotidienne :
- nettoyage surfaces ;
- vidage bacs ;
- contrôle visuel ;
- nettoyage filtres accessibles ;
- arrêt correct ;
- respect procédures.

Maintenance hebdomadaire :
- nettoyage approfondi ;
- contrôle joints ;
- contrôle température ;
- détartrage si nécessaire ;
- vérification roues/portes.

Maintenance mensuelle :
- contrôle consommation ;
- vérification ventilation ;
- nettoyage condenseur frigorifique si accessible ;
- contrôle sécurité ;
- inspection câbles/tuyaux.

Maintenance annuelle :
- contrôle professionnel ;
- remplacement pièces d’usure ;
- calibration ;
- contrat maintenance ;
- vérification gaz/électricité.

## 11. Équipement critique et équipement secondaire

### Équipement critique

S’il tombe en panne, l’activité s’arrête.

Exemples :
- four principal boulangerie ;
- chambre froide ;
- machine à café d’un café ;
- friteuse d’un snack ;
- lave-vaisselle d’un grand restaurant.

Pour les équipements critiques :
- choisir meilleure qualité ;
- garantie forte ;
- SAV local ;
- pièces disponibles ;
- prévoir solution de secours.

### Équipement secondaire

S’il tombe en panne, l’activité continue partiellement.

Exemples :
- blender secondaire ;
- vitrine supplémentaire ;
- petit robot ;
- chariot.

Pour les équipements secondaires :
- budget plus flexible ;
- occasion possible ;
- remplacement plus facile.

## 12. Erreurs fréquentes à éviter

1. Acheter avant de définir le menu.
2. Acheter trop grand.
3. Acheter trop petit.
4. Ignorer la consommation énergétique.
5. Ignorer le SAV.
6. Acheter sans garantie.
7. Acheter un équipement difficile à nettoyer.
8. Oublier la ventilation.
9. Ne pas vérifier les dimensions.
10. Ne pas former le personnel.
11. Acheter uniquement selon le prix.
12. Oublier les pièces de rechange.
13. Mélanger équipements domestiques et professionnels.
14. Ignorer la réglementation d’hygiène.
15. Ne pas prévoir maintenance.

## 15. Recommandations par budget

### Budget limité

Prioriser :
- équipement critique neuf ou très bon état ;
- petit matériel robuste ;
- occasion seulement si testée ;
- fournisseurs proches ;
- équipements multifonctions.

Éviter :
- équipement sans garantie ;
- marques inconnues sans pièces ;
- matériel domestique ;
- équipement trop grand.

### Budget moyen

Prioriser :
- marques fiables ;
- garantie ;
- équipement principal neuf ;
- équipements secondaires occasion contrôlée ;
- optimisation énergie.

### Budget élevé

Prioriser :
- performance ;
- faible consommation ;
- automatisation ;
- maintenance préventive ;
- ergonomie ;
- croissance future.

## 16. Équipements multifonctions

Un équipement multifonction peut réduire le nombre de machines.

Exemples :
- four mixte : cuisson vapeur + convection ;
- robot coupe : hacher + mixer + couper ;
- table réfrigérée : préparation + conservation ;
- batteur mélangeur : plusieurs accessoires ;
- lave-vaisselle à capot : haut débit.

Avantages :
- gain espace ;
- moins d’achats ;
- meilleure productivité.

Limites :
- panne plus critique ;
- prix plus élevé ;
- besoin formation ;
- maintenance plus importante.

---

## 17. Énergie et installation

Avant achat, vérifier :
- puissance électrique ;
- monophasé ou triphasé ;
- besoin gaz ;
- ventilation ;
- arrivée eau ;
- évacuation ;
- distance aux murs ;
- poids de l’équipement ;
- niveau du sol ;
- conformité installation.

Exemple :
Un four professionnel peut nécessiter une forte puissance électrique ou une installation gaz sécurisée.
Une chambre froide nécessite un espace ventilé et une installation spécialisée.
Une hotte doit être dimensionnée selon les équipements de cuisson.

## 18. Hygiène et matériaux

Matériaux recommandés :
- inox alimentaire ;
- plastique alimentaire pour bacs ;
- verre sécurisé pour vitrines ;
- joints faciles à nettoyer.

À éviter :
- surfaces poreuses ;
- rouille ;
- bois non adapté ;
- coins difficiles à nettoyer ;
- peinture écaillée ;
- joints abîmés ;
- équipements domestiques fragiles.

## 20. Comment le spécialiste IA doit utiliser ce manuel

Le spécialiste IA “Équipements Professionnels” doit :
- identifier le type d’activité de l’utilisateur ;
- demander le volume ou budget si nécessaire ;
- recommander les familles d’équipements adaptées ;
- expliquer les critères de choix ;
- éviter de proposer un équipement non adapté ;
- signaler les contraintes : espace, énergie, entretien, SAV ;
- comparer plusieurs options si possible ;
- donner une réponse pratique et professionnelle ;
- rappeler l’importance de l’hygiène, sécurité, maintenance et coût total ;
- proposer un score ou une checklist si l’utilisateur hésite entre plusieurs modèles.

Exemple de réponse attendue :
Pour une petite boulangerie, il faut prioriser un four adapté au volume de production, un pétrin dimensionné selon la quantité de pâte quotidienne, une chambre de fermentation, une balance précise, des tables inox, une armoire réfrigérée et des plaques/chariots. Si le budget est limité, il vaut mieux acheter neuf les équipements critiques comme le four et le pétrin, et envisager l’occasion contrôlée pour certains petits matériels.
